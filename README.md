# Crazy Runner in City — Inspired Web3 Runner

A Unity 3D endless platform runner inspired by the movement language of Crazy Runner in City.

## Planned gameplay
- 3D endless floating-city platforms
- Slopes, ramps, gaps and accelerators
- Auto-forward runner movement
- Left/right steering
- Jump
- Diamonds / collectible currency
- Obstacles and fall detection
- Power-ups
- Character skins
- Increasing speed/difficulty
- Mobile swipe + keyboard controls
- WebGL and Android targets

## Source
This project uses open-source Unity runner code/assets only where their licenses permit reuse. Proprietary Crazy Runner in City assets are not included.
